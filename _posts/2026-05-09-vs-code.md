# 告别终端孤岛：Claude Code 的 VS Code 深度集成指南

作为开发者，我们最讨厌什么？是频繁的上下文切换。在过去，使用 AI 编程助手往往意味着要在 IDE 和终端之间反复横跳——复制代码、粘贴提问、复制回答、再粘贴回编辑器。这种割裂的体验不仅打断心流，更让 AI 的潜力大打折扣。今天，我们要探讨的正是解决这个痛点的利器：Claude Code 的 VS Code 扩展。它将 AI 能力原生嵌入你的工作区，让代码与对话在同一视野内交汇。

## 关键概念：不只是个聊天框

Claude Code 的 VS Code 扩展并非简单地把网页版聊天塞进侧边栏，它提供了深度契合 IDE 工作流的图形界面。安装扩展时，CLI（命令行）工具也会一并集成，你可以直接在 VS Code 的集成终端里访问高级功能。

在开始前，请确保你的环境满足前置条件：
- VS Code 版本 **1.98.0** 或更高
- 拥有 Anthropic 账户（首次打开扩展时会要求登录）

## 实操演示：从安装到提效

### 1. 安装与启动

在 VS Code 中按 `Cmd+Shift+X`（Mac）或 `Ctrl+Shift+X`（Windows/Linux）打开扩展视图，搜索 "Claude Code" 并点击安装。如果安装后未生效，试试重启 VS Code 或在命令面板运行 "Developer: Reload Window"。

启动方式非常灵活，寻找界面上的 **Spark 图标（✱）** 即可：
- **编辑器工具栏**：右上角的 Spark 图标（需打开文件才会显示），这是最快的方式。
- **活动栏**：左侧边栏的 Spark 图标，可查看会话列表。
- **状态栏**：右下角的 "✱ Claude Code"，即使没打开文件也能用。

### 2. 精准提问：@-mention 与上下文感知

这是扩展最实用的功能之一。当你在编辑器中选中代码时，Claude 会自动看到高亮部分。按下 `Option+K`（Mac）/ `Alt+K`（Windows/Linux），甚至可以直接在提示框中插入带有行号引用的 @-mention（如 `@app.ts#5-10`）。

```text
> Explain the logic in @auth (fuzzy matches auth.js, AuthService.ts, etc.)
> What's in @src/components/ (include a trailing slash for folders)
```

> 💡 **实战技巧**：Claude Code 支持模糊匹配，输入部分文件名即可。对于大型 PDF，你甚至可以要求它只读取特定页码，节省宝贵的上下文窗口(context window)。

### 3. 安全的代码审查：内联 Diff 视图

当 Claude 提出修改建议时，扩展会展示原代码与建议代码的**并排对比视图**。你可以选择接受、拒绝，或者直接在 diff 视图中修改建议内容！如果你手动改了提议，Claude 会感知到你的修改，不会假设文件完全遵循了它的原方案。



![Inline Diff Review](assets/images/screenshots/inline-diff-review.png)



### 4. 模式切换与思维链

在提示框底部，你可以切换**权限模式**：
- **普通模式**：每次操作前询问。
- **计划模式 (Plan)**：Claude 会先描述计划，并在 VS Code 中以完整 Markdown 文档打开，你可以直接在文档中添加行内评论给出反馈，批准后它才会动手。
- **自动接受模式**：Claude 直接修改，无需确认。

遇到复杂逻辑？在命令菜单（输入 `/`）中开启 **Extended thinking（扩展思维）**，Claude 会花更多时间推理，思考过程会以折叠块显示，按 `Ctrl+O` 可展开/折叠所有思考块。

### 5. 多会话与工作区定制

你可以将 Claude 面板拖拽到次级侧边栏、主侧边栏，甚至作为编辑器标签页并排显示。通过命令面板的 "Open in New Tab" 或 "Open in New Window"，可以开启多个独立对话，并行处理不同任务。标签页上的小圆点会提示状态：蓝色代表等待权限确认，橙色代表后台任务已完成。

## 进阶技巧：从连接浏览器到外部工具

### 自动化浏览器任务
安装 Chrome 扩展（1.0.36+）后，你可以在提示框中使用 `@browser` 让 Claude 直接与浏览器交互：

```text
@browser go to localhost:3000 and check the console for errors
```

### 连接外部工具 (MCP)
通过 MCP（模型上下文协议），你可以赋予 Claude 访问外部 API 的能力。在集成终端运行以下命令添加 GitHub MCP 服务器：

```bash
claude mcp add --transport http github https://api.githubcopilot.com/mcp/ \
  --header "Authorization: Bearer YOUR_GITHUB_PAT"
```

配置好后，直接在聊天框输入 `/mcp` 即可在图形界面中管理这些服务器，无需离开 VS Code。

### 通过 URI 深度链接启动
扩展注册了 URI 处理程序，你可以从脚本或浏览器书签直接唤起 VS Code 中的 Claude 标签页，甚至预填提示词：

```text
vscode://anthropic.claude-code/open?prompt=review%20my%20changes
```

### Git Worktrees 并行开发
使用 `--worktree` 标志，你可以让 Claude 在独立的 worktree 中工作，互不干扰：

```bash
claude --worktree feature-auth
```

### 安全与隐私须知
你的代码不会被用于模型训练。但请注意，如果开启了自动编辑权限，Claude 可以修改 VS Code 配置文件。处理不受信任的代码时，建议开启 VS Code 受限模式或使用手动审批。

> ⚠️ **注意**：扩展会在本地运行一个内置的 IDE MCP 服务器（绑定在 `127.0.0.1` 随机端口），用于实现 diff 视图和读取选区等功能。如果你们公司使用了 `PreToolUse` 钩子来白名单 MCP 工具，记得把 `mcp__ide__getDiagnostics` 和 `mcp__ide__executeCode` 考虑进去。
