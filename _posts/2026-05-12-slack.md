# 告别频繁切屏：在 Slack 中直接派发 Claude Code 编码任务

作为开发者，你一定经历过这样的场景：团队在 Slack 频道里热烈讨论一个刚爆出的 Bug，错误日志和用户反馈刷刷往上滚。此时，你需要手动切到终端，找到对应的代码库，开始排查。这种在沟通工具和开发环境之间的频繁跳转，不仅打断思路，更拖慢了修复速度。

如果能让 AI 直接在对话上下文中接手编码任务呢？今天我们要聊的 **Claude Code in Slack**，正是为了消灭这种割裂感而生。

## 关键概念：无缝衔接的异步编码

Claude Code in Slack 的核心逻辑非常简单：**将对话上下文直接转化为编码行动**。当你在 Slack 中 `@Claude` 提出编码需求时，它不会像普通的聊天机器人那样只给建议，而是会在云端（Claude Code on the web）自动创建一个真实的编码会话，执行操作并提交代码。

它最擅长处理以下场景：
* **Bug 调查与修复**：Bug 刚在频道里曝光，立刻让 Claude 接手调查。
* **快速代码审查与修改**：基于团队反馈，让 Claude 直接实现小功能或重构代码。
* **协作调试**：当讨论串中包含了关键的错误复现步骤时，Claude 能直接利用这些上下文指导调试。
* **并行任务执行**：在 Slack 里派发任务，你继续其他工作，完成后收到通知。

## 实操演示：从零开始配置

要让 Claude 在你的 Slack 工作区里写代码，需要完成以下配置：

### 1. 安装与认证
首先，工作区管理员需要从 Slack App Marketplace 安装 Claude 应用。安装后，你需要将个人的 Claude 账号与 Slack 账号绑定：

1. 在 Slack 的 Apps 中点击 "Claude"，进入 App Home 标签页。
2. 点击 "Connect" 完成账号关联。



![Slack App Home Connect](assets/images/screenshots/slack-app-home-connect.png)



同时，确保你已经在 [claude.ai/code](https://claude.ai/code) 上开启了 Web 端访问权限，并连接了至少一个 GitHub 仓库。

### 2. 设置路由模式
这是最有趣的设计。在 Claude App Home 中，你可以配置 **Routing Mode（路由模式）**：

| 模式 | 行为 |
| :--- | :--- |
| **Code only** | 所有 `@Claude` 都路由到 Claude Code 会话。适合专门用于开发的频道。 |
| **Code + Chat** | 智能分析消息，自动在 Claude Code（编码）和 Claude Chat（写作、分析）间路由。适合团队单一入口场景。 |

如果你在 `Code + Chat` 模式下发现 Claude 把编码任务当成了普通聊天，只需点击 **"Retry as Code"** 即可纠正。

### 3. 邀请入频道
出于安全考虑，Claude 不会自动加入任何频道。你需要手动输入：
```bash
/invite @Claude
```
注意：**它只在公共或私有频道中工作，不支持 DM（直接消息）。**

### 4. 见证奇迹的时刻
当你在讨论串中 `@Claude` 提出编码请求时，整个流程如下：

1. **发起与检测**：你 `@Claude` 并描述任务，它自动检测编码意图。
2. **创建会话**：在 claude.ai/code 上创建新的 Claude Code 会话。
3. **进度同步**：Claude 在 Slack 串中推送状态更新。
4. **完成与审查**：任务完成，Claude `@` 你并附带摘要。你可以直接点击 **"View Session"** 查看完整过程，或点击 **"Create PR"** 直接发起 Pull Request。



![Slack Task Completion Pr Button](assets/images/screenshots/slack-task-completion-pr-button.png)



## 进阶技巧：让 Slack 里的 AI 更好用

### 上下文是一切的关键
当你在讨论串中 `@Claude` 时，它会收集该串内的**所有消息**作为上下文；如果是在频道中直接 `@` 它，它会查看频道的近期消息。这意味着，**在讨论串中召唤 Claude 效果最好**，因为那里包含了最密集的问题上下文。

> ⚠️ **安全提示**：Claude 会获取对话上下文来理解需求，也可能遵循上下文中其他消息的指令。因此，请务必只在可信的 Slack 对话中使用。

### 写出高转化率的 Prompt
想要 Claude 在 Slack 里表现优异，请求需要更具体：
* **提供坐标**：包含文件名、函数名或报错信息。
* **明确仓库**：如果从对话中看不出是哪个项目，主动告诉它。
* **定义完成标准**：告诉它什么是“做完了”——需要写测试？更新文档？还是直接提 PR？

### 选错仓库了怎么办？
Claude 会根据上下文自动选择仓库。如果它选错了，你无需重头来过，直接点击消息上的 **"Change Repo"** 按钮即可切换。



![Change Repo Dropdown](assets/images/screenshots/change-repo-dropdown.png)



### 局限性须知
目前该功能有几个硬性限制：仅支持 GitHub 仓库；每个会话只能创建一个 PR；会话消耗你个人 Claude 计划的额度；且必须拥有 Web 端访问权限，否则只会返回普通的聊天回复。

## 结语

Claude Code in Slack 的本质，是将 AI 编程助手无缝嵌入到了团队已有的沟通流中。它把“讨论 Bug”到“修复 Bug”之间的摩擦降到了最低，真正实现了异步、并行的现代开发节奏。
